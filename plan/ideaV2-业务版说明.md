# 智能报告生成：给业务同事的一页纸说明

> 这是 `ideaV2-核心路径.md` 的业务版，不含技术术语，用于向业务部门、管理层介绍这套系统「做什么、怎么做、需要大家配合什么」。

## 一、要解决什么问题

现在写一份周报/月报，大致要经历：找数、核对数、算同比环比、分析、写文字、排版、再让人复核。痛点大家都熟：

- **慢**：一份报告从取数到定稿要花大量时间，大部分耗在重复劳动上；
- **口径乱**：同一个指标，不同部门、不同报告算出来不一样，开会先吵口径；
- **数字容易错**：复制粘贴、改了数据忘了改结论，最怕报告发出去之后被指出数字不对；
- **说不清来源**：领导问"这个数怎么来的"，要翻半天 SQL 和 Excel 才能回答。

这套系统的目标不是"让 AI 替你写报告"，而是：**把找数、核对、初稿这些重复劳动交给系统，把口径判断、结论定调、最终签发留给人。**

## 二、系统怎么工作：像一条有质检的流水线

可以把它想象成一条工厂流水线，中间每一道工序都有质检，人只在头尾两个关口把关：

```
你提需求 → 【关口1：你确认提纲和口径】 → 系统自动取数 → 系统核对数据
        → AI 照着核对过的数据写初稿 → 系统逐个数字复查 → 【关口2：你审批签发】
```

分步骤说：

| 步骤 | 谁来做 | 做什么 |
| --- | --- | --- |
| 1. 提需求 | 你 | 用一句话说清楚要什么报告，比如"生成上周研发效能周报" |
| 2. 确认提纲 | **你（关口 1）** | 系统列出报告提纲、要用哪些指标、统计哪段时间，你确认或调整。**口径在这里锁定，之后不会变** |
| 3. 自动取数 | 系统 | 按确认好的口径去数据库取数。只能读、不能改，每一步都留有记录 |
| 4. 数据质检 | 系统 | 检查数据是否完整、是否在合理范围。数据有问题就停下来报告，**不会把有问题的数据包装成结论** |
| 5. 写初稿 | AI | AI 只能看到质检合格的数据，照着写文字和图表。**它写的每一个数字，都必须能指出来自哪条数据** |
| 6. 数字复查 | 系统 | 机器把初稿里的每个数字和数据源逐一比对，对不上就打回重写。**数字全对是发布的硬性条件** |
| 7. 审批签发 | **你（关口 2）** | 你看到的每个结论旁边都能点开"这个数从哪来"，确认无误后签发 |

## 三、这套系统的三个特点

### 1. 不懂就问，绝不瞎猜

如果你说的指标有歧义（比如"成功率"可能指两个不同指标）、或者数据有问题，系统会**停下来问你**，而不是自己挑一个猜着往下走。宁可多问一句，也不产出一份看起来漂亮但口径错误的报告。

### 2. 每个数字都有"出生证明"

报告里的任何一个数字、比例、排名，都能一路追溯到：用的哪个指标、哪段时间、哪次查询、原始数据是什么。领导问"这个数怎么来的"，点一下就能看到，不用再翻 Excel。

### 3. AI 只动笔，不做主

AI 在这条流水线里只负责两件事：把你的需求整理成提纲、把核对过的数据写成通顺的文字。它**接触不到原始数据库，改不了数字，下不了结论**。判断口径、认定原因、定调措辞、最终签发，都是人的事。

## 四、第一阶段做什么、不做什么

**做：** 选**一个**内部周报场景（初步定为研发效能周报），固定一套模板、约 10～20 个常用指标，先把"数字准确、来源可查"这条流水线跑稳。

**暂不做：**

- 不做"自动分析原因"——第一阶段报告只说"发生了什么"（数据和变化），"为什么发生"仍由人来判断，系统最多提示"可能与某事件有关，请确认"；
- 不做对外客户报告——先在内部把质量跑稳；
- 不做任意报告类型——先做好一种，再复制到月报、复盘等场景。

## 五、需要业务同事配合什么

这个项目能不能成，一半取决于业务侧的三件事：

1. **定口径**：项目启动时，需要指标负责人把 10～20 个核心指标的定义、算法、适用范围一次性说清楚并确认。这是一次性投入，之后所有报告共用，也顺带解决了"开会吵口径"的老问题。
2. **把关口**：报告生成前确认提纲（约 1～2 分钟），发布前审批签发。这两个关口是留给人的决策权，不是走形式。
3. **给反馈**：试运行期间，改了哪里、为什么改，随手标一下。这些反馈会用来持续改进系统。

## 六、怎么衡量做得好不好

上线后用四个大家都能看懂的数来评价：

| 指标 | 说明 |
| --- | --- |
| 数字准确率 | 报告中的数字与数据源是否一致——**要求 100%，一个都不能错** |
| 一次通过率 | 系统生成的报告不经修改直接通过审批的比例 |
| 人工耗时下降 | 对比现在人工写一份报告的时间，目标下降一半以上 |
| 来源可查率 | 报告中的关键结论能否一键追溯到数据来源 |

## 七、一句话总结

> **这不是一个"AI 帮你写作文"的工具，而是一条"数字保真、来源可查"的报告生产线：机器干重活并层层质检，人守住口径和签发两个关口。**
