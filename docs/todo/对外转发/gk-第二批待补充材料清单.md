## 三、业务语义与样例

### 7. 现有报告成品样例（最重要的材料之一）

| | |
|---|---|
| **要什么** | 贵方现行报告的**最终成品** 1~2 期：Word 或 PDF 均可，涉密数字可打码/替换，我们需要的是**章节结构、表格版式与行文风格**，不是数字本身。 |
| **为什么** | 取数逻辑材料告诉了我们「数字怎么算」，但报告自动生成还需要知道「文章长什么样」：章节先后顺序、每段先说什么后说什么、表格如何排版、增减如何措辞（「增长」「下降」「与上年基本持平」的使用习惯）。有成品样例，生成的报告才能贴合贵方现行体例，而不是我们凭空设计一套贵方还要重新适应的格式。 |
| **优先级** | **高（报告自动生成的阻塞项）** |

### 8. 数字展示精度与单位规范

| | |
|---|---|
| **要什么** | 报告成文时数字的展示规则：单位用万元还是亿元（是否分指标而异）、保留几位小数、四舍五入还是截断、百分比保留几位、负数如何表述。若第 7 项的成品样例足够典型，此项可从样例中归纳，仅需贵方确认。 |
| **为什么** | 材料已明确计算过程按小数点后 8 位汇总，但**最终呈现给读者的精度与单位**未说明。同一个数按万元两位小数还是亿元一位小数展示，读感完全不同；四舍五入规则不一致还会造成分项之和与合计尾数对不上的观感问题。 |
| **优先级** | **中** |

### 9. 各报告段落的业务语义说明

| | |
|---|---|
| **要什么** | 对每个报告段落（对应本批 10 份材料各自覆盖的段落）各补充一小段**业务层说明**，包含三点：<br>（a）**这段话在讲什么业务问题**——例如「反映当月全市财政收入总体形势，供行领导判断收入进度是否正常」；<br>（b）**写给谁看**——行领导/上级行/地方政府部门，决定详略与语气；<br>（c）**措辞与文风要求**——例如「先讲总量再讲增速，增速超过两位数须点评原因」「负增长表述用『下降』不用『减少』」「段末惯例给一句趋势判断/不做判断只陈述事实」。<br><br>每段 3~5 行文字即可，格式不限，业务同事口述后记录成文亦可。 |
| **为什么** | 这是决定自动生成报告**「像不像人写的」**的关键材料。取数逻辑保证数字对，而这份说明保证话说得对：同样一组数字，写给行领导的快报和报给上级的正式报告，详略、语气、结论倾向完全不同。没有这份说明，生成的文字只能是「数字的复读」，无法达到可直接签发的质量。它与第 7 项成品样例互补：样例是「范文」，本项是「写作要求」。 |
| **优先级** | **高** |
