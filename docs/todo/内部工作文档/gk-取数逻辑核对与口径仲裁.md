## 二、三方口径基本盘（先说一致的）

三方**互相印证、可视为基本可信**的口径（下文销号表与术语表以此为底）：

- 通用取数模板五要素（新材料 10 文件 × V3.0 七接口的 SQL 完全同构）。
- 辖内范围 = `treasury_code = X OR admin_treasury_code = X`（一层下钻）；市级（treasury_level='3'）再套一层查孙库（新材料每个文件尾部 + V3.0 §7.2/§7.3）。
- 本期 = 当月单月 `current_period_amount`；年累计 = 直读 `year_to_date_amount`，不逐月累加（新材料通篇 + V3.0 接口四 §7.6）。
- 库存 = 月末最后一天 `balance` 求和（xduanluo1 L28 + V3.0 接口一 §7.3）。
- 同比四公式 + 上年基数为 0 标「无同比」（新材料每文件尾部 + V3.0 各接口 §7.7，字面一致）。
- 汇总计算按小数点后 8 位（10 个文件尾部逐字相同），与 DDL `decimal(18,8)` 呼应——但**展示精度**三方都没说（见仲裁 B7）。

## 六、结语：仲裁闭环判定标准

按失败关闭原则，**「没仲裁完」的唯一后果是相应资产不入库，而不是猜一个口径先跑起来**。分层的闭环门槛：

1. **glossary（第 2 层）定稿门槛**：A1（地方级）、A12（全口径逐指标确认）、A2/B1（非税公式）、B6（其他税收基数）四组闭环——这四组直接决定「全口径/地方级/非税/其他税收」四个高频词条的定义正确性，闭环前这些词条**连同引用它们的 few-shot 一起冻结**；其余「明确」级词条可先行入库。
2. **报告指标模板（第 4 层）入库门槛**：在 1 的基础上再加 A4（日均分母）、A5（负数规则）、A6（利润枚举）、A9（上月年累计跨年）、B2（逐段落排名依据）、B7（展示精度）闭环，且每个指标模板经 metric-wizard 试查 + 五重校验 + 与对方成品报告（待索取材料⑦）逐数比对通过。
3. **自由问数放开门槛**：完整科目码表（S3）+ T 码/数字码包含关系到手并落 guard 防重复计数之前，收入表自由问数保持降级受限（识别不了口径一律拒答）——详见姊妹篇《gk-智能问数与报告生成落地方案与能力边界》。
4. **最终依据排序**：数据服务源代码 > 对方书面确认 > 数据验证反推 > 文档字面。本轮 22 项中 A3/A7/A14/A15 这类「显性笔误」拿到源代码即自动闭环，优先催源代码（S15）性价比最高。

所有仲裁结论回填本文第四章表格（新增「仲裁结果」列），全部闭环后本文归档、口径进入《gk-语义描述四层接入方案》定稿流程。
