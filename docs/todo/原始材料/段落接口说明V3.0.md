## 接口一：国库收入分级汇总及排名查询接口

### 1. 接口概述

本接口用于查询国库收入分级汇总数据及全市排名，支持按国库代码和所属年月条件查询全口径国库收入、中央级国库收入、省级国库收入、地方级国库收入的年累计金额及同比增减情况，同时查询国库库存余额及全市排名。

### 2. 接口路径

`GET /api/treasury-revenue-rank/query`

### 3. 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| treasuryCode | String | 是 | 国库代码 |
| statDate | String | 是 | 统计日期，格式为yyyyMM（如202603） |

### 4. 请求示例

```bash
curl "http://localhost:8082/api/treasury-revenue-rank/query?treasuryCode=1005160000&statDate=202603"
```

### 5. 响应字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 国库代码 | String | 查询的国库代码 |
| 国库名称 | String | 国库名称 |
| 统计日期 | String | 统计日期（yyyyMM格式） |
| 全口径国库收入年累计金额 | BigDecimal | 全口径国库收入年累计金额 |
| 全口径国库收入同比增减 | String | 同比增减幅度（百分比，无同比时为"-"） |
| 中央级国库收入年累计金额 | BigDecimal | 中央级国库收入年累计金额（budget_level=1） |
| 中央级国库收入同比增减 | String | 同比增减幅度 |
| 省级国库收入年累计金额 | BigDecimal | 省级国库收入年累计金额（budget_level=2） |
| 省级国库收入同比增减 | String | 同比增减幅度 |
| 地方级国库收入年累计金额 | BigDecimal | 地方级国库收入年累计金额（budget_level=3,4,5） |
| 地方级国库收入同比增减 | String | 同比增减幅度 |
| 国库库存余额 | BigDecimal | 国库库存余额（月末数据） |
| 全市排名 | Integer | 在同级国库中的排名（按库存余额降序） |

### 7. 业务逻辑说明

#### 7.1 收入数据查询逻辑

根据需求文档，收入数据查询采用以下规则：

| 指标 | 科目代码 | 预算级次条件 |
|------|----------|--------------|
| 全口径国库收入 | T010101, T010201, T010401, T010601 | 无 |
| 中央级国库收入 | T010101, T010201, T010401, T010601 | budget_level IN (1) |
| 省级国库收入 | T010101, T010201, T010401, T010601 | budget_level IN (2) |
| 地方级国库收入 | T010101, T010201, T010401, T010601 | budget_level IN (3,4,5) |

#### 7.2 国库代码范围查询

查询当前国库代码及其下属子国库的数据：

```sql
SELECT treasury_code FROM treasury_basic_info 
WHERE treasury_code = :treasuryCode OR admin_treasury_code = :treasuryCode
```

#### 7.3 库存余额查询

库存余额查询月末最后一天的数据：

```sql
SELECT SUM(balance) FROM treasury_balance_journal 
WHERE treasury_code IN (子国库代码列表) AND stat_date = 'yyyy-MM-dd'
```

其中日期格式为 `yyyy-MM-dd`，取当月最后一天（如202603对应2026-03-31）。

#### 7.4 全市排名计算

1. 获取当前国库的上级国库代码（admin_treasury_code）
2. 查询所有拥有相同上级国库代码的同级国库列表：

```sql
SELECT treasury_code FROM treasury_basic_info 
WHERE admin_treasury_code = (SELECT admin_treasury_code FROM treasury_basic_info WHERE treasury_code = '1005160000')
```

3. 依次计算每个同级国库的库存余额：

```sql
SELECT SUM(balance) FROM treasury_balance_journal 
WHERE treasury_code IN (SELECT treasury_code FROM treasury_basic_info WHERE treasury_code = 'xxx' OR admin_treasury_code = 'xxx') 
AND stat_date = '2026-03-31'
```

4. 按库存余额降序排序，确定当前国库的排名

#### 7.5 同比增减计算

```
同比增减幅度 = (本期金额 - 上年同期金额) / 上年同期金额 × 100%（百分比，上年基数为0时标注"-"）
```

### 8. 科目代码映射

| 指标名称 | 科目代码 |
|----------|----------|
| 全口径国库收入 | T010101, T010201, T010401, T010601 |

### 9. 错误响应

| HTTP 状态码 | 错误信息 | 说明 |
|-------------|----------|------|
| 400 | 参数校验失败 | 请求参数格式错误或缺失 |
| 500 | 服务器内部错误 | 数据库查询失败等 |

## 接口二：一般公共预算收入查询接口

### 1. 接口概述

本接口用于查询一般公共预算收入本月之前所有月份的金额及同比增减情况，年累计金额及同比增减情况，以及同级国库同期一般公共预算收入的金额及同比增减情况和排名。支持按国库代码、所属年月和统计口径（1=全口径，2=地方级）条件查询。

### 2. 接口路径

`GET /api/treasury-budget-revenue/query`

### 3. 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| treasuryCode | String | 是 | 国库代码 |
| statDate | String | 是 | 统计日期，格式为yyyyMM（如202603） |
| statType | Integer | 是 | 统计口径：1表示全口径，2表示地方级 |

### 4. 请求示例

```bash
curl "http://localhost:8082/api/treasury-budget-revenue/query?treasuryCode=1005160000&statDate=202603&statType=2"
```

### 5. 响应字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 国库代码 | String | 查询的国库代码 |
| 国库名称 | String | 国库名称 |
| 统计日期 | String | 统计日期（yyyyMM格式） |
| 统计口径 | Integer | 统计口径（1=全口径，2=地方级） |
| 统计口径名称 | String | 统计口径名称（全口径/地方级） |
| 每月数据列表 | List<MonthlyData> | 本月之前所有月份的执行数据 |
| 同级国库数据列表 | List<SiblingData> | 同级国库的同期数据 |
| 同级国库排名 | Integer | 在同级国库中的排名（按库存余额降序） |

#### MonthlyData（每月数据）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 月份 | String | 月份（yyyyMM格式） |
| 本期金额 | BigDecimal | 本期执行金额 |
| 本期同比增减额 | BigDecimal | 本期金额 - 上年同期本期金额 |
| 本期同比增减幅度 | String | 同比增减幅度（百分比） |
| 年累计金额 | BigDecimal | 年累计执行金额 |
| 累计同比增减额 | BigDecimal | 年累计金额 - 上年同期累计金额 |
| 累计同比增减幅度 | String | 同比增减幅度（百分比） |

| 字段名 | 类型 | 说明 |

| 累计同比增减额 | BigDecimal | 年累计金额 - 上年同期累计金额 |

### 7. 业务逻辑说明

#### 7.1 统计口径与预算级次

根据statType参数确定查询条件：

| statType | 名称 | budget_level条件 |
|----------|------|-----------------|
| 1 | 全口径 | 无条件（查询所有预算级次） |
| 2 | 地方级 | 根据treasury_level动态确定 |

#### 7.2 预算级次动态条件

根据查询国库代码在treasury_basic_info表中的treasury_level字段值，动态确定budget_level的查询条件：

| treasury_level | budget_level条件 |
|----------------|-----------------|
| 3 | IN ('3', '4', '5') |
| 4 | IN ('4', '5') |
| 5 | IN ('5') |

#### 7.3 数据查询范围

查询当前国库代码及其下属子国库的数据：

```sql
SELECT treasury_code FROM treasury_basic_info 
WHERE treasury_code = :treasuryCode OR admin_treasury_code = :treasuryCode
```

#### 7.4 同比计算公式

```
本期同比增减额 = 本期金额 − 上年同期本期金额
本期同比增减幅度 = 本期同比增减额 ÷ 上年同期本期金额 × 100%
累计同比增减额 = 年累计金额 − 上年同期累计金额
累计同比增减幅度 = 累计同比增减额 ÷ 上年同期累计金额 × 100%
```

> 注意：上年基数为0时标注"无同比"

#### 7.5 同级国库查询

同级国库的查询逻辑：

```sql
SELECT treasury_code FROM treasury_basic_info 
WHERE admin_treasury_code = (
    SELECT admin_treasury_code FROM treasury_basic_info 
    WHERE treasury_code = '1005160000'
)
```

#### 7.6 排名计算

1. 获取当前国库及其所有同级国库的库存余额
2. 按库存余额降序排序
3. 确定当前国库的排名位置

## 接口三：税收收入明细及同比情况查询接口

### 1. 接口概述

本接口用于查询税收收入本月之前所有金额、年累计金额和同比增减情况，以及占一般公共预算收入的比重。支持按国库代码、所属年月和统计口径（1=全口径，2=地方级）条件查询。

包含以下数据：
- 税收收入月度数据
- 增值税、国内增值税、企业所得税、个人所得税、城市维护建设税、房产税、城镇土地使用税、耕地占用税、土地增值税、契税、印花税、其他各项税收

- 专项收入、行政事业性收费收入、罚没收入、国有资源有偿使用收入
- 同级国库同期一般公共预算收入

本期同比增减额 = 本期金额 − 上年同期本期金额
本期同比增减幅度 = 本期同比增减额 ÷ 上年同期本期金额 × 100%（上年基数为0时标注"无同比"）
累计同比增减额 = 年累计金额 − 上年同期累计金额
累计同比增减幅度 = 累计同比增减额 ÷ 上年同期累计金额 × 100%（上年基数为0时标注"无同比"）
```

```
国有土地使用权出让收入占地方财力比重 = 国有土地使用权出让收入本期金额 ÷ 地方财力本期金额 × 100%
```

SELECT SUM(current_period_amount) FROM treasury_income_detail

```

#### 7.7 同比计算公式

```
本期同比增减额 = 本期金额 − 上年同期本期金额
本期同比增减幅度 = 本期同比增减额 ÷ 上年同期本期金额 × 100%（上年基数为0时标注"无同比"）
累计同比增减额 = 年累计金额 − 上年同期累计金额
累计同比增减幅度 = 累计同比增减额 ÷ 上年同期累计金额 × 100%（上年基数为0时标注"无同比"）
```
