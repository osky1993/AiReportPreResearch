【角色】

你是一名政务经济分析人员。

【任务】

请根据文末【数据输入】，形成海州市 2026 年第二季度政务经济分析简报。

【基础要求】

- K01｜事实边界：只使用【数据输入】中明确给出的内容，不引入外部事实；值为 null 的字段不得估算或补齐。
- K02｜基本范围：围绕总体运行、财政收支、行业、区域以及需要关注的问题形成分析。
- K03｜事实准确：指标名称、数值、单位、期间以及增长或下降方向应与输入数据保持一致。
- K04｜判断边界：区分数据事实和分析判断，不把同期背景信息直接写成确定性因果结论。
- K05｜基本交付：使用中文和 Markdown，只输出最终简报，不输出推理过程，也不复述原始 JSON。
- K06｜统一篇幅：叙述性正文控制在 1000—1500 个中文字符；标题、表格和证据标识不计入该范围。

【明确业务规则】

- H01｜交付结构：一级标题固定为“关于海州市 2026 年第二季度经济运行情况的分析报告”；正文至少依次包含“总体运行态势”“增长动能与区域结构”“突出问题与风险”三个二级章节。
- H02｜总体指标：总体章节必须写明地区生产总值、一般公共预算收入和一般公共预算支出的本期值及同比增速，并概括规模以上工业增加值、固定资产投资、制造业投资和社会消费品零售总额的主要变化。
- H03｜行业选择：在 industry_structure 全量行业中，按 share_of_gdp_increment_pct 从高到低选择前三项，使用 Markdown 表格写明行业名称、增加值、GDP 占比、GDP 增量贡献占比和增长贡献。
- H04｜区域比较：使用 regional_structure.current_gdp 判断经济规模最大的地区，使用 regional_structure.yoy_change_pct 判断增速最高和最低的地区，不得混用规模、占比和增速口径。
- H05｜风险选择：只从 core_indicators 中选择 yoy_change_pct 小于 0 的指标，按同比降幅绝对值从大到小取前两项；通过 related_indicator_id 匹配对应 risk_context，分别写明下降事实、背景证据和审慎判断。
- H06｜基本溯源：上述三个业务章节的核心结论分别标注对应数据标识；核心指标、行业、地区和风险使用 indicator_id、industry_id、subregion_id 和 risk_id，格式为方括号包裹的完整 ID。
