【角色】

你是一名政务经济分析人员。

【任务】

请根据文末【数据输入】，形成海州市 2026 年第二季度政务经济分析简报。

【基础要求】

- K01｜事实边界：只使用【数据输入】中明确给出的内容，不引入外部事实；值为 null 的字段不得估算或补齐。
- K02｜基本范围：围绕总体运行、财政收支、行业、区域以及需要关注的问题形成分析。
- K03｜事实准确：指标名称、数值、单位、期间以及增长或下降方向应与输入数据保持一致。
- K04｜判断边界：区分数据事实和分析判断，不把同期背景信息直接写成确定性因果结论。
- K05｜基本交付：使用中文和 Markdown，只输出最终简报，不输出推理过程，也不复述原始 JSON。
- K06｜统一篇幅：叙述性正文控制在 1000—1500 个中文字符；标题、表格和证据标识不计入该范围。

【明确业务规则】

- H01｜交付结构：一级标题固定为“关于海州市 2026 年第二季度经济运行情况的分析报告”；正文至少依次包含“总体运行态势”“增长动能与区域结构”“突出问题与风险”三个二级章节。
- H02｜总体指标：总体章节必须写明地区生产总值、一般公共预算收入和一般公共预算支出的本期值及同比增速，并概括规模以上工业增加值、固定资产投资、制造业投资和社会消费品零售总额的主要变化。
- H03｜行业选择：在 industry_structure 全量行业中，按 share_of_gdp_increment_pct 从高到低选择前三项，使用 Markdown 表格写明行业名称、增加值、GDP 占比、GDP 增量贡献占比和增长贡献。
- H04｜区域比较：使用 regional_structure.current_gdp 判断经济规模最大的地区，使用 regional_structure.yoy_change_pct 判断增速最高和最低的地区，不得混用规模、占比和增速口径。
- H05｜风险选择：只从 core_indicators 中选择 yoy_change_pct 小于 0 的指标，按同比降幅绝对值从大到小取前两项；通过 related_indicator_id 匹配对应 risk_context，分别写明下降事实、背景证据和审慎判断。
- H06｜基本溯源：上述三个业务章节的核心结论分别标注对应数据标识；核心指标、行业、地区和风险使用 indicator_id、industry_id、subregion_id 和 risk_id，格式为方括号包裹的完整 ID。

【业务完整性与质量保障规则】

- M01｜期间口径：本期统一指 reporting_period，对比期统一指 comparison_period；不得将季度数据表述为月度、半年度或全年数据，也不得引入输入之外的期间。
- M02｜数值口径：优先使用 JSON 已提供的本期值、对比值、变化额和同比值，不重新计算并替换已有结果；金额、比例、增速和贡献度统一保留两位小数，项目数量保持整数。
- M03｜财政口径：财政收支差额和收入覆盖支出比例只使用 fiscal_structure 已提供字段；负差额只能表述为“收支平衡仍需关注”，不得升级为“财政赤字”或确定性的财政失衡。
- M04｜行业口径：行业增加值、同比增速、GDP 占比、GDP 增量贡献占比和增长贡献百分点分别对应不同字段；不得把 share_of_gdp_increment_pct 与 growth_contribution_pp 混为同一指标。
- M05｜区域口径：规模比较只使用 current_gdp，增速比较只使用 yoy_change_pct，占比比较只使用 share_of_region_gdp_pct；并列时保持 JSON 原顺序。
- M06｜证据映射：核心指标、行业、地区和风险分别引用相应 ID；无专用 ID 的 fiscal_structure 和 data_quality 字段使用完整 JSONPath，例如 [fiscal_structure.revenue_expenditure_gap]。
- M07｜引用位置：证据标识放在其直接支持的句子末尾；不得在一段结尾只放一个 ID，却用它支撑该段中多个来源不同的事实。
- M08｜比较证据：行业排名、地区最高或最低等比较结论必须覆盖参与比较的数据集合；地区比较至少同时列出 [EAST][WEST][SOUTH][NORTH]，不得只引用最终胜出项。
- M09｜风险证据：每项风险同时引用对应 core_indicators 的 indicator_id 和 risk_context 的 risk_id；背景证据引用对应 risk_id 或其 context_evidence JSONPath，不得跨风险拼接证据。
- M10｜空值处理：null 不得写成 0、“无变化”“保持稳定”或横线，也不得参与排序、同比、趋势、占比或其他派生计算。
- M11｜缺失披露：明确说明城镇调查失业率上年同期值缺失，因此不作同比判断；明确说明民间投资本期值缺失，因此不作本期规模、增速和趋势判断。
- M12｜质量说明：正文末尾增加“数据质量与口径说明”二级章节，集中披露缺失项及其对结论边界的影响，不把缺失值混入风险排序。
- M13｜异常判定：风险候选必须满足 core_indicators.yoy_change_pct 小于 0，并按该数值从小到大排列，即降幅绝对值从大到小；不得把低增速但仍为正增长的指标列为下降风险。
- M14｜风险要素：每项风险必须包含本期值、同比降幅、对应背景证据和审慎判断四个要素；房地产开发投资在前，货物出口总额在后。
- M15｜归因边界：context_evidence 只支持“可能相关、仍需核验”的关联判断；如果没有匹配的 risk_context，只能描述下降事实，不得自行推测原因。
- M16｜完整结构：最终顺序为“核心结论—总体运行态势—增长动能与区域结构—突出问题与风险—数据质量与口径说明”；“核心结论”和“数据质量与口径说明”分别置于 H01 三个业务章节之前和之后。
- M17｜核心结论：核心结论分别概括经济基本盘、主要增长动力和两个核心风险，不引入后文没有展开的新指标，也不加入输入数据无法支持的工作成效或预测。
- M18｜内容归位：行业前三项放入唯一一张行业表；区域比较放在表后正文；两个风险使用两个项目符号；缺失值只在数据质量章节集中说明。
